# CAFFEINATE_

> Neural Frequency Terminal — [caffeinate.club](https://caffeinate.club)

Binaural frequency terminal for developers. Real frequencies. Real focus. The only boost you need at 3AM when the deadline is real and the coffee ran out.

## What is this?

A single-page web app that generates real binaural beats through the Web Audio API, themed around caffeine culture and late-night coding. Nine dose profiles (Espresso, Red Bull, Cold Brew, Yerba Mate, Copium, sudo rm -sleep, Stack Overflow, Works On My Machine, caffeinate_d) plus independent ambient noise (white/pink/brown) for focus.

Inspired by the early internet era of frequency terminals and the macOS `caffeinate -d` command.

## Stack

- Single HTML file. No dependencies. No build step.
- Web Audio API (binaural oscillators, noise generation, SFX)
- Pure CSS 3D (rotating dose icons)
- Share Tech Mono + Press Start 2P typography
- Deployed on Vercel

## Deploy

```bash
git clone https://github.com/YOUR_USERNAME/caffeinate-club.git
cd caffeinate-club
# just open index.html — or deploy to Vercel
vercel
```
